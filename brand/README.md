# Echo Charlie Labs — brand assets

The marks are rendered from `source.html` (the Newsreader serif from Google
Fonts on the site's green) with `render.mjs`; the PNGs are the canonical
files. Slack, GitHub and app stores round icons themselves, so the squares
are left square.

| File | Use |
|---|---|
| `ecl-paper-1024.png` / `-512` | **Primary icon**: off-white EC with a green rule. Slack workspace icon, GitHub org avatar, touch icon. Highest contrast at small sizes. |
| `ecl-green-1024.png` / `-512` | Brand-green EC on the dark field, for large placements (the original touch-icon look). |
| `ecl-framed-1024.png` / `-512` | Off-white EC inside the hairline frame from the social image. |
| `ecl-wordmark-1600x400.png` | Lockup: green tile + "Echo Charlie Labs" + tagline. Channel headers, email signatures, the org README. |

## Colours

| Token | Hex | Where it comes from |
|---|---|---|
| Field | `#14201A` | background of `og.png` and the touch icon |
| Green | `#1F6B4A` | rule and accents on `og.png`; the Worth My Fee green |
| Green, bright | `#2A8A63` | letterform green on the dark field (lifted for legibility) |
| Paper | `#F7F5F0` | the site's page colour |
| White | `#FFFFFF` | wordmark title |
| Muted | `#A9B6AC` | wordmark tagline |

Type: Newsreader (Google Fonts), weight 500, tight tracking. Product marks
(HeyBooker's coral "B.", Worth My Fee's green "?") stay their own; this set
is only for the company.
